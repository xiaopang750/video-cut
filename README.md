# 绘本剪辑台

把「照着绘本朗读的录像」剪成「一页一页的绘本图文视频」：提取原声 → Whisper 语音识别 → 文字稿自动对齐到每一页 → 可视化剪辑（删掉读错的地方、补录替换、调整翻页时间）→ 生成视频 / PDF。

- 地址：<http://localhost:3031>（pm2 托管）
- 技术栈：Node.js（Express）+ React（Vite）；ffmpeg、whisper.cpp、模型全部放在项目目录里

## 启动 / 停止

```bash
npm start        # pm2 启动（端口 3031）
npm run stop     # 停止
npm run restart  # 重启
npm run logs     # 看日志
```

## 素材怎么放

每本绘本一个文件夹，放在电脑上任意位置就行，导入时上传：

```
A Present for Mum/
├── FragmentVideo_626047.402894.mov   # 朗读视频，默认按文件名排序后依次拼接（导入时可以拖动调整；也支持 mp4 / m4a / mp3 / wav）
├── ...
├── IMG_4313.JPG                      # 绘本照片，默认按序号从小到大（导入时可以拖动调整）
├── ...
└── zimu.rtf                          # 文字稿（rtf / txt）
```

文字稿里用 `#pic#图片引用` 标记「上面这段文字对应哪张图」（也兼容 `#_4313`、`#4313`）。引用既可以写完整文件名（如 `#pic#IMG_4399_2.JPG`），也可以省略 `IMG_`、图片后缀或末尾的重复序号（如 `#pic#4399_2`、`#pic#4399`）；找不到且引用不大于图片数量时，当作「第几张图」（按导入时确认的图片顺序）。同一张图可以出现多次，每段文字都会成为视频里的一页。段落之间用空行分组（通常英文一行 + 中文一行），合成画面时组与组之间会留一点间距。

没有文字稿时，每张图算一页，文字可以在编辑器里补。

## 使用流程

1. **导入绘本**：列表页右上角「导入绘本」，把电脑上的绘本文件夹拖进弹窗（或点击选择文件夹），上传前分三步确认：
   - **① 视频顺序**：视频以卡片从左到右排列，按这个顺序拼接成整段录音（默认按文件名排序）；点画面可以播放
   - **② 图片顺序**：默认按文件名里的序号从小到大；点图片看大图，每张图下面标出被文字稿用在哪几页
   - 视频、图片调整顺序有两种方式：**按住卡片拖到新位置**（卡片顶部有「⠿ 拖动」，放下的位置有橙色竖线；拖到弹窗上下边缘会自动滚动，从最下面拖到最上面也可以），或者**点卡片左上角的序号，输入要和第几个交换**
   - 挪动过的会标橙色，并显示「原第 N」和挪动方向；步骤标签上有橙点表示这一步有调整，可以一键恢复默认顺序
   - **③ 文字稿**：按 `#pic#序号` 切好的每一页（文字 + 配图）逐页列出，找不到的图片、没用到的图片会提示；有多个 rtf / txt 时可以选用哪个
     - 改配图有三种方式：点这一页的图片从列表里选（列表里每张图可以放大看，也可以设为先不配图）；在图片下面**输入第几张**；或者把顶部图片条里的图直接拖到这一页上。图片条里的图都有编号，点一下可以放大看
     - 改文字：点「改文字」直接编辑（每行一句，空一行分组）
     - 改过的页标紫色，可以单独恢复或「全部恢复」；确认后的文字和配图会记下来，重新初始化也不会丢
   - 名字和已有的绘本重名时会提示「已经导入过」，可以直接打开已有的那本，或者改名 /「仍然导入」存成新的一本
   - 确认后上传，文件保存到项目的 `data/<绘本名>/`，确认的顺序会记下来（重新初始化也按这个顺序）；默认导入后立即初始化，列表按创建时间倒序，刚导入的排在最前面并高亮
   - 删除项目时，上传的素材可以选择一起删掉
2. **初始化**（4 分钟的录音大约 40 秒）：
   - ffmpeg 提取每段视频的音频，无损拼接；同时导出 320k 的 `原始音频.mp3`
   - whisper.cpp（large-v3-turbo，Apple Silicon 用 Metal 加速）识别出每个词的时间
   - 把文字稿和识别结果做序列比对，推荐每一页从哪里开始、到哪里结束
   - 同时把各段视频按音轨对齐、合并成一个低清预览视频（和识别并行，不额外耗时）
3. **编辑**：
   - 顶栏中间是播放控制；右边切换「对照 / 原始视频 / 合成画面」。对照模式下左边原始视频、右边合成画面，跟着时间轴同步播放，画面按可用空间尽量放大
   - 点合成画面可以打开**大图**看清图上的字：跟着播放自动翻页，←/→ 翻页，空格播放，Esc 关闭
   - 时间轴从上到下四条轨道：**页面**（每页的时间段）、**视频段**（原始视频的分段线，按文件顺序）、**音频**（按响度画的波形，播放过的部分变深）、**识别文字**（按句分组，颜色跟随所在的页；加粗是和文字稿对上的词，灰色是文字稿里没有的）
   - 调整图文和音频的对应：
     - 拖动页面轨道上两页之间的白色把手（拖回初始化时推荐的位置附近会自动吸附回去）
     - 或者在右侧当前页卡片上直接调**开始 / 结束时间**：‹ › 每次挪 0.1 秒，点时间可以直接输入（如 `1:02.5`）；改过的时间标橙色，「恢复」一键回到初始化时推荐的开始 / 结束时间
     - 快捷键 `[` / `]`：把当前页的开始 / 结束时间设为播放头位置
   - 剪辑后时间轴不会收缩，原始录音始终完整显示，所有修改都标在原位置上（播放和生成视频时自动按修改后的结果）：
     - **删除**（红色）：拖选一段按 Delete，这段变成红色区块，两端是加粗红色虚线和剪刀，播放和生成时跳过；直接拖动红线可以调整范围；选中红色区块里的一段再按 Delete 是恢复
     - **替换**（黄色）：拖选一段后「替换为补录」或「现场录音」，原录音标黄（不播放），新录音紧跟在后面
     - **新增**（绿色）：「插入补录」或没有选区时的「现场录音」，从橙色竖线（播放头）处插入
     - **空白**（灰色）：「插入空白」，在橙色竖线处插入一段静音（位置规则和插入补录一样），可以填多少毫秒，也有常用长度可选；插入后点灰色区块可以试听前后、用 ‹ › 每次加减 50 毫秒或直接输入毫秒数、回撤
     - 点区块两端的图标（✂ / ⇄ / +）打开这处修改的工具栏：类型和时长｜开头、结尾各一个微调器（‹ › 每次 0.05 秒，中间显示当前位置）｜「试听前后」（从前 2 秒播到后 2 秒）｜「回撤」。补录放到时间轴上后会自动打开这个工具栏
     - **现场录音**：录完会先上传识别、自动去掉首尾空白，在预览框里可以「试听前后」（插入位置前 2 秒 + 新录音 + 后 2 秒，波形上标出新录音的位置）或「只听新录音」，满意再「插入到时间轴 / 替换选区」；「重新录」或关掉弹窗，这段录音会被丢弃
     - 补录的首尾空白会自动去掉；新录音也可以从两头选中删掉一部分（等于微调首尾）；整段删掉时，新增 = 回撤这处新增，替换 = 这一处改成删除原录音
     - 工具栏右边的「成片」显示最终视频的长度
   - 「贴合字词」打开时，拖动选区边缘或翻页把手会自动贴到最近的字词边界，方便刚好剪在两个词之间（拖动时按住 Option 临时关闭）
   - 时间轴工具栏分三块：左边「撤销 / 重做」（⌘Z / ⇧⌘Z）；中间「插入到播放头」一组（补录文件 / 空白 / 现场录音）；右边成片长度、贴合字词、缩放和快捷键（颜色说明也在快捷键弹层里）。删除、替换、重录某一段：先在波形上拖选，选区上会弹出操作条。窗口窄的时候工具栏会逐级收成图标，不会被挤出去
   - 所有修改自动保存；所有按钮悬停都有说明
   - 右侧「修改记录」：只列**和初始化时不一样**的地方，时间轴上的每一处修改（删除 / 新增 / 替换 / 翻页）是一条记录，显示操作时间、类型和位置。扩大、缩小、微调都算同一处：挨着的删除会合并成一处，从中间恢复一段会分成前后两处，同一页的翻页只有一条（调回原来的位置就不算修改，记录自动去掉）。每条记录可以单独：
     - **回撤**：这里恢复成初始化时的样子；回撤了的不算修改，收在底部「已回撤」里，需要时可以**重新应用**。位置按原始录音记，回撤前面的不会让后面的错位
     - **导出 / 导入**：「修改记录」右上角「导出」把全部记录存成一个 JSON 文件（保存到浏览器的「下载」里），用到的补录 / 现场录音会以无损 FLAC 一起打包进去；「导入」选这个 JSON 就能恢复（会替换当前的记录，⌘Z 可以撤销）。换台电脑、重新导入同一本绘本后也能用；原始录音长度或页数对不上时会先提示
     - **删除**：等于回撤这处修改并且去掉这条记录，之后不能再重新应用（删错了可以 ⌘Z）
     - 点记录会跳到时间轴上对应的位置并选中；文字、图片、画面设置是直接保存的，不进修改记录
   - 右侧卡片上的铅笔按钮可以修改这一页的文字、给这一页换图片（弹窗顶部可以直接切到别的页）
   - 「画面设置」可以调整照片高度、字体字号、水印卡片文字、翻页转场、音量标准化等，右侧实时预览（画面固定 3:4、750×1000，水印固定在左下角）
4. **确认生成**：输出到 `output/<绘本名>/`：
   - `<绘本名>.mp4`：750×1000（3:4，和参考图一致），H.264 + AAC
   - `<绘本名>.mp3`：剪辑后的音频（320k）
   - `<绘本名>-原始音频.mp3`：初始化时提取的原始音频
5. **导出 PDF**（列表页每个项目上的「PDF」）：把每一页合成图按顺序拼成
   - 整本长图（一页到底，代表整个故事）→ `<绘本名>.pdf`
   - 或一图一页 → `<绘本名>-分页.pdf`
   - 生成后项目卡片上会显示「PDF 已生成」（排版方式、生成时间），旁边可以直接打开 / 下载，「PDF」按钮带绿色对勾；再打开 PDF 对话框也能打开、下载、在访达中显示或重新导出。关掉对话框在后台生成的，完成后会弹提示
   - 生成过视频的项目，卡片上同样会显示「视频已生成」，可以直接播放 / 下载

### 编辑器快捷键

| 操作 | 快捷键 |
| --- | --- |
| 播放 / 暂停 | 空格 |
| 删除选区 | Delete |
| 试听选区 | S |
| 撤销 / 重做 | ⌘Z / ⇧⌘Z |
| 当前页的开始 / 结束时间设为播放头 | `[` / `]` |
| 上一页 / 下一页 | ↑ / ↓ |
| 后退 / 前进 1 秒（按住 Shift 5 秒） | ← / → |
| 放大 / 缩小时间轴 | `=` / `-`，或 ⌘ + 滚轮、触控板双指捏合 |
| 拖动时临时不吸附到词边界 | 按住 Option |
| 选中一个词 | 双击这个词 |

## 目录说明

```
data/        导入时上传的素材（删除项目时可以选择一起删掉）
output/      生成的视频、音频、PDF
workspace/   每个项目的中间文件和剪辑记录（删除项目会清掉对应目录）
vendor/      whisper-cli 二进制、识别模型、whisper.cpp 源码
server/      后端（Express）
web/         前端（React + Vite，构建产物在 web/dist）
scripts/     setup.sh 一键安装
```

## 拷贝到别的电脑

整个目录拷过去即可，依赖都在目录里：

- **另一台 Apple Silicon 的 Mac**：直接 `npm start`（需要本机有 Node.js 18+）。
- **其他平台 / 缺文件时**：运行 `npm run setup`，会重新安装 Node 依赖、构建前端、编译 whisper.cpp（需要 cmake）并下载缺失的模型。国内网络可以用镜像：`HF_ENDPOINT=https://hf-mirror.com npm run setup`。

## 技术细节

- **识别**：whisper.cpp `large-v3-turbo`（q5_0 量化），逐个视频片段识别，关闭上下文延续（`-mc 0`）避免重复幻觉；从文字稿里提取人名（Chip、Biff…）作为提示词。词级时间来自 DTW 对齐，DTW 普遍偏晚约 0.25 秒，程序会用音频能量的起音点自动校准。
- **对齐**：Gotoh 仿射罚分序列比对；英文用编辑距离 + Soundex 音近匹配（Mum/mom、Biff/beef），中文用拼音匹配；录音只读英文时自动忽略中文行。重读时会匹配到最后一遍，翻页点放在两页之间最长的停顿里。
- **原始视频预览**：iPhone 视频的音轨通常比画面晚 0.x 秒开始，所以每段都从音轨起点截取画面，缩成 360p 后合并，并记录每段在预览视频里的位置，保证和音频时间轴逐段对齐。
- **剪辑**：所有音源统一为 44.1kHz 立体声 PCM，按剪辑列表在 Node 里按采样精确拼接，切点做 5ms 淡入淡出防爆音；浏览器端用 Web Audio 无缝预览同一份剪辑列表。
- **合成**：@napi-rs/canvas + sharp，版式按参考图 `doc/pic.png` 实测还原（PingFang SC、米白底 `#F2F1EA`、左下角文件卡片水印）。
